# FLUX 3 Image Klein Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** golem draws FLUX 3 Image Klein pictures (text, and text + reference images) the way ComfyUI does, and krea2-mobile can use it for Generate, Compose and Edit.

**Architecture:** A new package `flux3` beside `krea2`, built on the same `vk.K2` kernels (MM fp8/fp16, Norm, Rope, Act, Attn, Conv, Pix) plus whatever new shaders the DiT block or the Flux2 VAE need. Each stage is transcribed from ComfyUI commit `20b46065` and tested against fixtures recorded by `ref/flux3/dump.py`. krea2-mobile picks the server flag by model and wires its `compose`/`edit` routes.

**Tech Stack:** Go, Vulkan compute (GLSL → SPIR-V, existing build in `vk/shaders`), Python ComfyUI for the reference.

**Spec:** `docs/superpowers/specs/2026-10-19-flux3-klein-design.md`

## Global Constraints

- Reference ComfyUI: a worktree of `/mnt/data/dev/ComfyUI` at `origin/master` (≥ `9fa63b0a`) in `/mnt/data/dev/ComfyUI-flux3`, sharing the same `.venv`; never change the user's checkout (branch `wip`).
- Model files under `/mnt/data/dev/ComfyUI/models/`: `diffusion_models/flux3-image-klein-bf16.safetensors`, `text_encoders/qwen3vl_4b_fp8_scaled.safetensors` (already there; fall back to `qwen3vl_4b_bf16.safetensors` from the Klein repo only if ComfyUI refuses the fp8 one), `vae/flux2-vae.safetensors`. Workflows copied to `ref/flux3/workflows/`.
- Fixtures under `testdata/flux3` (symlink to `/mnt/data/golem-testdata/flux3`, like krea2). A test that finds none skips.
- Model constants from ComfyUI: hidden 3072, heads 24 × 128, in channels 128, txt_in 20480, rope axes [32,32,32,32] θ 10000, image rope scale 0.5, MLP ratio 3, LayerNorm/RMSNorm eps 1e-6, shift 1.93586, pad token 151643, pad to multiple of 80, taps `[4,8,12,16,20,24,28,32]`.
- Defaults (steps, sampler, scheduler, CFG, sizes) are read from `ref/flux3/workflows/flux3_klein_bf16_t2i.json` and `_i2i.json`, and written as constants with that file cited.
- Commit messages follow golem's style: `flux3: <what it now does, as a sentence>`. Comments and READMEs in English, golem's voice.
- krea2 behaviour and tests unchanged; `go test ./krea2/...` passes at every task.
- Every perf claim is a measured number on the RX 9070 XT (memory: perf is the point).
- Card exclusivity: no test or dump runs while another process holds the card (`ref/krea2/README.md` explains the fault).

## Review Focus

1. Prompts longer than one pad block (> 80 tokens) and exactly 80: padding lands on the next multiple, pads at rope position 1, the DiT sees them. Test in Task 2.
2. Sizes not multiple of 16, or above MaxPixels: refused with a clear error, not a crash. Test in Task 6.
3. A reference image of another aspect ratio than the output, and two references: ids on l = −1, −2 and the right shapes. Test in Task 6 (fixture `mi2i`).
4. CFG 1 vs CFG > 1 with an empty negative: the uncond runs with its own length (no padding to cond's length). Test in Task 4.
5. krea2-mobile with Krea 2 selected keeps Compose/Edit hidden and the routes answering as before. Test in Task 8.

### Task 1: Recorder `ref/flux3/dump.py`
